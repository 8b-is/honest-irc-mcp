# honest-irc-mcp

**MCP server for [quantum-proof messaging + honesty-auth](https://github.com/8b-is/honest-irc)**
over [Model Context Protocol](https://modelcontextprotocol.io) `2026-07-28`.

## Tools

- `msg`
- ` search`
- ` honesty`
- ` verify`
- ` rooms`
- ` peers`
- ` music`
- ` quant`

## Usage

```bash
pip install mcp
python server.py
```

Requires: honest-ircd running on :9667.
